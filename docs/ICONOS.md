# Iconos del frontend

Los iconos actuales usan Material Symbols. Están marcados en el código por la clase `material-symbols-outlined` y pueden reemplazarse por SVG, PNG o componentes propios.

Ubicaciones principales:

- `src/components/Navbar.tsx`: navegación, notificaciones, perfil y cierre de sesión.
- `src/pages/DashboardPage.tsx`: acciones rápidas, eventos, retrasos e imprevistos.
- `src/pages/SchedulePage.tsx`: OCR, horarios, formulario y borradores.
- `src/pages/GroupsPage.tsx`: grupos, propuestas y votaciones.
- `src/pages/ProfilePage.tsx`: perfil y preferencias.
- `src/pages/auth/`: formularios de acceso y registro.

Para encontrarlos todos: `rg "material-symbols-outlined" src`.
